A small OS, funded by the people who run it.

Grintion-OS takes no ads, ships no telemetry, and answers to no vendor roadmap. Donations pay for the unglamorous parts: the machines that boot every ISO, the offline signing key, and the hosting a signed package repository needs.

Where the money goes

Four line items, all tied to work this project has not finished yet.

Release CI

Machines that actually boot it

BIOS and UEFI boot tests, install tests, encrypted persistence and the independent release audit all run on a self-hosted KVM runner.

Bare metal

Hardware that is not a VM

Used mini PCs and laptops to run the ISO on real firmware and publish the bare-metal logs the roadmap still lists as missing.

Signing

An offline release key

Dedicated hardware for the release signing key and the key ceremony, so a downloaded image can be verified instead of trusted.

Hosting

A signed package repository

Bandwidth and storage for a public garb repository. The signed-repository tooling exists; the server does not.

Today nobody is paid a salary from this project. If a month raises more than it costs, the balance stays with the project and appears in the ledger — it is not treated as income.

Help that costs nothing

  • Bare-metal boot logs. The roadmap still has no published real-hardware evidence. One successful boot on your machine, with the log attached, closes a gap.
  • Second-host rebuilds. Cross-host reproducibility is unproven. Building the ISO on your host and reporting the hash is a real contribution.
  • Desktop and GPU testing. XFCE, i3, Plasma, LXQt and Sway are verified in QEMU; your hardware and drivers are not.
  • Translations. The handbook exists in English and Spanish. Other languages do not.
  • Packages. A working .garb package for a tool you rely on is more useful than a feature request.

When you report a problem, include the version (cat /etc/grintion/version), whether it is the live image or an installed system, the exact command, and the output. The sanitized bundle from grintion-report covers most of it.

Funding policy

  • No advertising, sponsored content, or affiliate links in the image, the documentation, or this page.
  • No telemetry, crash reporting, or phone-home service, funded or otherwise.
  • A donation buys nothing: no roadmap control, no priority support, no feature. Sponsors are acknowledged only if they ask.
  • Money is spent on infrastructure and hardware the release process depends on. Anything else is listed in the ledger with a reason.
  • Donations are not tax-deductible. The project is not a charity and does not pretend to be one.
